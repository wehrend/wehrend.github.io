== How does a CPU work 2 - Table of contents

== *From Combinational to Sequential Logic - Introduction*

_link:/pages/11_sequential_logic/[Introduction to Sequential Logic]_

We get from purely combinational logic circuits without any form of memory to sequential logic circuits
with some type of memory (mostly flip-flops).

== *Clocks, Flip-Flops and Registers*

_link:/pages/12_clocks_and_registers/[Clocks, Flip-Flops and Registers]_

We make a leap into the area of sequential logic and introduce some concepts vital for sequential logic,
like clocks, flip-flops and registers.

== *Memory*

_link:/pages/13_memory/[Memory Organization]_

We introduce the concept of memory and show how it is used in a CPU: memory hierarchy, RAM and ROM,
SRAM vs. DRAM and the register file.

== *Finite State Machines*

_link:/pages/14_automata/[Finite State Machines]_

We introduce Mealy and Moore (and Medvedev) machines and design a traffic light and a sequence detector -
from the state diagram to the circuit.

== *RISC-V: The Instruction Set*

_link:/pages/15_risc_v/[RISC-V: The Instruction Set]_

We decide what our CPU should be able to do: RISC vs. CISC, the RISC-V instruction set, the instruction formats
and a first assembler program.

== *The Data Path*

_link:/pages/16_datapath/[The Data Path]_

We combine the ALU, registers and memory into a data path and look at the execution phases
of the different instruction types.

== *The Control Unit*

_link:/pages/17_cpu_control/[The Control Unit]_

The last missing piece: the control unit generates the control signals from the opcode. In the end, our example
program runs clock cycle by clock cycle through the finished CPU.
