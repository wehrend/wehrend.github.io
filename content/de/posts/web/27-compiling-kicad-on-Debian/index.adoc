*Dies ist eine aktualisierte Fassung des Blogbeitrags vom 08.05.2025, damit Sie auch die neueste Version von KiCad samt Abhängigkeiten kompilieren können.*

Mit meinem neuen Hobby kam der Wunsch, eigene Platinen entwerfen und bauen zu lernen. Deshalb habe ich angefangen, die
Open-Source-ECAD-Lösung KiCad zu nutzen. Inzwischen möchte ich mich auch an dem Projekt beteiligen, aber um den Code zu kompilieren,
muss man ein paar Hürden nehmen: die Abhängigkeiten zusammensuchen und installieren, den richtigen Branch wählen, der sich auch
tatsächlich kompilieren lässt, und so weiter. Hier möchte ich meine Erfahrungen damit teilen.

Klonen Sie zuerst das GitLab-Repository:

    git clone https://gitlab.com/kicad/code/kicad.git
    git checkout 9.0

Anschließend müssen Sie einige Abhängigkeiten installieren. Hier eine hoffentlich vollständige Liste:

    sudo apt-get install cmake libgl-dev libglew-dev libcurl4-openssl-dev ngspice xfonts-scalable libocct-data-exchange-dev \
    libocct-draw-dev libocct-foundation-dev libocct-modeling-algorithms-dev libocct-modeling-data-dev libocct-ocaf-dev \
    libocct-visualization-dev protobuf-compiler libprotobuf-dev swig python3 python3-pip libwxgtk3.0-gtk3-dev \
    unixodbc unixodbc-dev libsecret1 libgl-dev libglu1-mesa-dev freeglut3-dev libglew-dev libglm-dev libnng-dev

Zuerst bauen wir Protobuf (wir verwenden eine getaggte Version, um Probleme mit Abseil und utf8_range zu vermeiden):

    # Build-Werkzeuge installieren
    sudo apt install cmake git g++ autoconf automake libtool curl make unzip

    # Protobuf klonen und bauen
    cd software
    git clone https://github.com/protocolbuffers/protobuf.git
    cd ./protobuf
    git fetch --tags
    git checkout v21.12

    # Alte Builds entfernen
    rm -rf build CMakeCache.txt
    mkdir build && cd build

    cmake .. \
      -DCMAKE_BUILD_TYPE=Release \
      -DCMAKE_INSTALL_PREFIX=/opt/protobuf \
      -DCMAKE_POSITION_INDEPENDENT_CODE=ON \
      -Dprotobuf_BUILD_TESTS=OFF

    make -j8
    sudo make install

Jetzt können Sie endlich KiCad selbst bauen...

    git clone https://gitlab.com/kicad/code/kicad.git
    git checkout 8.0
    mkdir -p build/release
    cd build/release
    cmake ../.. \
    -DCMAKE_BUILD_TYPE=Release \
    -DCMAKE_INSTALL_PREFIX=/opt/kicad \
    -DUSE_GLEW=ON \
    -DGLEW_INCLUDE_DIR=/usr/include/GL \
    -DGLEW_LIBRARY=/usr/lib/x86_64-linux-gnu/libGLEW.so \
    -DGLU_LIBRARY=/usr/lib/x86_64-linux-gnu/libGLU.so \
    -DOPENGL_gl_LIBRARY=/usr/lib/x86_64-linux-gnu/libGL.so \
    -DOPENGL_INCLUDE_DIR=/usr/include/GL
    make -j8
    sudo make install
