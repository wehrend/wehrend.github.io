      Das Odoo-Frontend anpassen

      Heute möchte ich Ihnen zeigen, wie Sie Ihr Odoo-Frontend anpassen können. Ich gehe dabei nicht tief auf OWL ein, sondern zeige nur die grundlegenden Schritte, um Änderungen über HTML5, CSS und JavaScript umzusetzen.

      Tauchen wir ein und machen uns die Füße nass.

      Wir beginnen mit einer kurzen CSS-Datei, die die Ansicht verändert (in meinem Beispiel werden die Dreieckspfeile in den Rückstellungsberichten ausgeblendet). Sie können aber natürlich jedes andere Element (oder Attribut) nach Belieben ändern.

      provisions.css

      1

      .fa-caret-down {
    display: none !important;
    }

      Legen Sie diese Datei unter folgendem Pfad ab: static/src/css/provisions.css

      Zum Schluss müssen wir Odoo die neu hinzugefügte Datei bekannt machen, indem wir sie in die Frontend-Assets eintragen, hier konkret ins Backend-Bundle:

      manifest.py

      1

      # Asset Bundles
    'assets': {
        'web.assets_backend': [
            'my_module_provisions/static/src/css/provisions.css',
        ],
    },

      In der vollständigen Datei sieht das so aus:
